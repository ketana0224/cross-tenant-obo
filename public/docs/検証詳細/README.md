## 証跡と公開範囲

公開するのは、構成条件、操作、期待値、観測結果、原因として確認できた範囲、未検証事項。ログの実IDは意味を持つラベルへ置き換え、トークン・個人情報・実URL・相関ID・画面原本は掲載しない。

実機認証とツール呼び出しを検証したが、疑似API・合成データを使用した部分は実Snowflakeや業務データの検証ではない。生ログを公開していないため、公開資料だけで全試行を独立監査・完全再現できるわけではない。

証跡の読み方は[検証方法と限界](../Preview/検証方法と限界.md)、公開基準は[公開と非公開のポリシー](../Preview/公開と非公開のポリシー.md)を参照。
