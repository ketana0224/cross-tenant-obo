# cross-tenant-obo

Copilot Studio と Microsoft Foundry のマルチテナント連携について、**OBO・個別 OAuth・アプリ認証／認可**と、**API・MCP・A2A**の成立条件・実機での成立／不成立パターンを整理するリポジトリです。

ホスト場所、APIのアプリ登録先、トークン発行元、本人／アプリの権限を区別します。実行エラーを製品非対応と同一視せず、未検証の構成も明示します。

## 公開／非公開の構成

```text
README.md             公開する入口
.gitignore            公開対象の明示的な許可リスト
public/               新規作成した匿名化資料と設定テンプレート
  docs/
  examples/
private/              今後の非公開成果物・既存資産へのローカル索引
既存の各フォルダー    移動・上書きせず保持。既定でGit対象外
```

公開対象は **README、.gitignore、許可リストにある public/ 配下のファイルだけ**です。既存コード・実行状態・ログ・原本・環境設定は公開対象に含めません。ファイル名の許可は匿名化済みであることを保証しないため、内容確認も必要です。

既存資産は移動・変更していません。ルートREADMEと、承認された `.gitignore` だけを更新しています。フォルダー分離はアクセス制御ではなく、`.gitignore` は既に追跡されたファイルやGit履歴から情報を消す仕組みでもありません。

公開前の確認手順は [公開ポリシー](public/docs/公開と非公開のポリシー.md) を参照してください。GitHubへのpush、公開範囲の変更、ライセンスの決定はこの整理作業には含みません。
